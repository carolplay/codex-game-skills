# 项目背景与操作授权

本文件维护用户设定；执行流程见[V2-OPERATIONS](V2-OPERATIONS.md)，任务策略与分支覆盖见[visit-plan](../skills/play-whiteout-survival-macros/references/visit-plan.md)。历史版本不是额外审批或执行限制。

## 目标与授权

用户将游戏运行视为低成本沙盒试验：优先跑通流程、完成日常、扩大覆盖、固化可执行宏。虚拟资源与操作失误是可接受成本，不为资源保值增加审批或保守跳过；这不是对外部系统“绝无风险”的技术保证。

四个既有角色均已授权当前版本宏开发和执行，包括主号。成熟角色使用同一完整适用清单；低等级只按实际解锁区别，失败不等于未解锁。账号身份与具体策略读取本地绑定和角色配置，不据历史账号定位缩减范围。

已授权的游戏内操作包括导航、领取、派遣、使用虚拟资源、处理弹窗、正常重连和重启、恢复页面、采样、修宏与同轮定向复测。具体次数和预算是策略参数；已有授权不重复请求。模型可处理宏尚不能完成的流程，操作与结果单独记录。

科研与建筑升级保留为独立能力，不属于日常，不因空队列、红点或补积分启动；训练、治疗仍属日常。采集不带英雄。其他任务偏好按visit-plan和本地策略执行，不自动扩展到新账号、外部通信或真实支付。真实支付由用户本人完成；系统权限、平台强制审核与私有数据管理另行有效。

## 机器运行时段与登录

三班为America/Vancouver本地一班21:00、二班03:00、三班09:00，是用户方便时指定机器运行的安排，不是游戏强制刷新或日常截止。实际UTC游戏日、奖励冷却、周／四周轮转及活动窗口分别核验；四周不等于自然月。既有双日猎熊由其独立规格控制。

指定运行时段优先执行、接续日常与实际补欠，非必要开发、V3研究、文件整理和其他对话不挤占执行。只有阻断当前任务的修订才插入本轮；修复后立即接续未完成项。

CUA与用户正常物理输入按并行使用处理。键鼠活动、用户在电脑前或切到其他应用，本身不代表操作冲突、撤权或接手，不据此自行暂停、要求用户离开键鼠或让出日常。仅用户明确暂停／接手，或实际窗口、身份、输入效果失效时，按相应情况处理。平台明确暂停自动解锁或拒绝输入属于工具阻断，不能由本项目规则解除，也不解释成用户主动叫停。

账号显示在其他设备／其他地方登录，是用户正常登录造成的预期游戏断线。指定机器运行时段内直接正常重连，重核身份、窗口与页面后续检查点，不询问是否接手、不自行取消任务或排程。只有用户明确暂停、接手或指定手动占用才让出。反复断线有界恢复并记录技术偏差，不设置永久接手确认。

Orchestrator已取消，当前leader直接控制WOS，不申请外部时段或发送交接通知。保留单一执行锁与lease。旧V1排程保持暂停，维护或清理文件不改变游戏排程。

## 本地存储上限

本项目本地总占用不得超过5GB（5,000,000,000字节），包括源码、版本库、local-data、模板、日志、临时文件及项目专用CrossMacro开发／运行产物；不得搬到其他本地目录规避上限。已安装游戏和系统／通用共享依赖不属于项目产物。

4.5GB为提前维护线：先清理可再生成的缓存和非复用图片，历史日志可无损压缩；仍无法降回维护线以下则停止新批次并提示，不自动扩大额度，也不暗删必要日志。日志保留服从总额约束，不能无限累积。运行和维护以scripts/project_storage.py统一计量。

## 判断与证据

工具描述如实指出页面、按钮与效果，例如NPC详情、自己发起集结与加入他人集结分别识别。游戏断线、窗口路由错误、系统锁屏、权限拒绝与用户叫停分别归因，不把一种问题扩大成全部项目无限期暂停。恢复与拒绝范围处理见V2-OPERATIONS。

资源／任务重要性待与用户讨论，草案见[RESOURCE-TASK-PRIORITIES](RESOURCE-TASK-PRIORITIES.md)；排序不减少日常覆盖。余额、私有身份与运行日志留本地；画面默认临时处理，按运行规范只留明确可复用模板。
