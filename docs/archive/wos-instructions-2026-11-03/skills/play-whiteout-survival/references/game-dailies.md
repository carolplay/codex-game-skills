# 核心游戏日常

本层只回答游戏里做什么、怎样确认完成；设备输入、会话与审批交由执行层，资源优先度由账号目标层决定。先核验目标角色与实际炉子，读取本角色近期状态，不读其他角色余额来代替。

## 执行顺序

结合倒计时、当前任务积分及活动实际收益调整顺序：

1. 先完成免费收益检查：募兵所、炼晶实验室、曙光学院、宠物技能、律令所、战争学院，以及VIP/商店/签到；每项记为已领、冷却中、未解锁、需资源兑换或未验证。读取 [references/free-rewards.md](free-rewards.md) 后操作，不因红点或可点击按钮就认定免费。随后领取已完成队列、离线和探索挂机收益、联盟互助及已达成日常宝箱。
2. 灯塔情报：尽量清空当前所有营救、英雄之旅、普通野兽，不因日常次数或宝箱已达成而提前停止；体力不足或时限将至则记录剩余项。先检查领主体力旁的“丰盛的招待”及可用体力宠物技能。保留行军位，等待短途队伍返回再继续。NPC新手/大师悬赏不纳入普通日常，即使与情报在同一地图也不自动推进；须由调用线程另行规划。避开玩家野外攻击；需协调的NPC集结按调用范围判断。完成后领奖并等待奖励动画结束，检查是否还有被重叠图标挡住的任务；新手/大师悬赏会连续解锁下一号，不为清地图自动追做。
3. 免费招募、剩余免费竞技场挑战、VIP/签到/商店免费物品。确认免费按钮和剩余次数；不要把钥匙或钻石按钮当成免费。
4. 宠物技能和寻宝、海岛收益；领取已完成寻宝再派剩余次数，优先可用的高品质藏宝点。
5. 收取并补训练、治疗、研究、空闲资源点采集队列。检查城镇供暖和幸存者健康。长期研究或较大资源开销需判断当前目标，避免随意升级。
6. 周常和活动按剩余时间及实际收益处理；日常最高宝箱已领后优先维护队列，不为多余积分浪费稀缺材料。

调用方加入雪原游历挂机、无尽试炼、银行、冰原巨兽自动加入或兵营定时策略时，读取 [references/optional-dailies.md](optional-dailies.md)。这些项目的授权与资源预算由调用方指定，不从任务名推断所有消耗均可接受。

具体界面经验见 [references/ui-workflows.md](ui-workflows.md)，仅在相关操作时读取。坐标是历史示例，不是固定点击脚本。


## 核验与频率

先普通情报和可满仓收益，再按冷却处理其他任务；调用方的竞技场时段等策略优先。固定UTC/每日/滚动/周循环/活动分开，已达冷却无需每次重查。领取与兑换、启动与完成分开记。兵营优先晋升现有低阶，再新训最高可用阶；数量按当前速度与下次本角色预计访问时间倒推，留完成余量，不写死7/15小时或旧数量。

已验证纯展示奖励弹层可在已知安全空白处关闭并合并最终核验；新弹窗、选择、成本、身份及最终结果必须观察。遵循工具自身操作规则。
