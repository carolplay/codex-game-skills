# WOS wiki贡献准备

当前只准备稿件，不自动注册账号、提交站外编辑或发送消息。公开稿不带游戏账号、余额、机器路径、私人截图或运行日志。

资料采用三层：

| 资料源 | 当前使用方式 | 可贡献性 |
|---|---|---|
| [Whiteout Survival官方Wiki](https://www.whiteoutsurvival.wiki/) | 覆盖英雄、建筑、研究、宠物、专家和活动，优先交叉核对机制 | 页面贡献入口需进一步核实 |
| [WOS Forge Wiki](https://wiki.wosforge.org/wiki/Main_Page) | 建筑、资源、专家和事件等综合百科，当前优先准备目标 | 首页明确接受新文章与更正，可创建账号后编辑；现阶段不提交 |
| [WSCO活动/攻略目录](https://www.whiteoutsurvival-community.com/tools/wiki/events.html) | 补充日常路径和周期活动资料 | 不将攻略推断直接当游戏实测 |

“最完整”目前按本项目任务覆盖、规则细节、更新状况与可贡献入口评估，没有可靠依据宣称某站全面胜出。当前优先WOS Forge，保留官方Wiki与WSCO来源，后续可将同一份已核实材料适配给覆盖更完整的站点。

## 准备稿件

1. 炼晶：普通提炼与首次半价超级提炼的成本区分、次数含义。
2. 专家：兵营图标领取的奖励与新训练/升级操作分开说明。
3. 三班：把情报刷新、补给领取、每日和周活动分开；四周不是自然月。

每条采用“现有页面→建议补充→来源→本地实测范围→仍未知”结构。截图如需公开，先生成不含账号和余额的裁切证据，不能上传完整私人游戏画面。
