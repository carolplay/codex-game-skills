# 原生UI与设备故障

本工作区的机器时段、正常重连、锁与恢复以[当前运行规范](../../../docs/V2-OPERATIONS.md)为准；不恢复旧Orchestrator、角色派发或默认30分钟时限。其他调用场景遵从调用方的既有授权和显式deadline。

同bundle应用可能同时存在安装路径与Wrapper路径，绑定实际运行实例。按当前工具文档先观察，AX不足时使用截图；每次动作后读取新状态。尺寸、显示拓扑或身份变化后重新核验，不沿用动画中的旧坐标。

| 类型 | 区分与处理 |
|---|---|
| 游戏断线／其他设备登录 | 属正常游戏连接状态；指定机器运行时段内直接正常重连并核验，不能推断用户叫停或另设接手确认。 |
| 窗口路由失败 | `cgWindowNotFound`／`noWindowsAvailable`不直接证明锁屏、权限或卡死；按当前规范有界正常恢复。 |
| 系统／平台明确拒绝 | 按具体原文和作用范围停止，不能用截图可见或旧成功推断输入仍获允许。 |
| 游戏未知页面 | 由已授权开发agent识别、查资料、采样和恢复，不当成系统权限故障。 |

用户操作键鼠、登录或切换应用本身不是撤权；用户明确叫停或工具实际不可用时才按范围处理。明确要求手动解锁时照实报告，不混为游戏异地登录。持续同一阻断有界等待／记录，不让每角色重复撞错。

实际操作与结果、重连、恢复、耗时及证据留调用方日志；读取不到的token或credit记未知，不借重演或额外截图补统计。
